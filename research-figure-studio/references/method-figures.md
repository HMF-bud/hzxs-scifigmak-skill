# 方法图：从科学关系到原生矢量对象

本路线整合整体构图、学术排版和拓扑连接检查。直接使用本包规范与构建器即可，不依赖其他方法图skill。图形从真实输入、处理、共享/独立对象、对照与输出建立，参考只提供设计，不自动成为科学内容来源。

## 结构与布局

1. 从明确材料记录节点、标签、角色、方向、分支汇合、反馈与终点。用稳定ID区分节点身份和显示文字；共享模型与分别训练对象必须在有向关系上可区分。
2. 三方案可以采用并行路径、泳道、分层模块等不同阅读结构，但逻辑图一致；全部使用整体构图、排版和拓扑能力，不给三个技能各分一案。由用户在统一问答环节选择。
3. 冻结标签含义后测真实字体和换行，决定节点大小、组间距和画布。短标签优先，不用不断缩字解决超载。
4. 固定节点几何后生成连线。移动/缩放节点即使内容未变，也须重算相邻连线和避让通道。

减少多层外框和无义空白。相同形状尽量对应相同科学角色；输入素材不同时代表分析结论。框和短文字为主、小线图形辅助，颜色强调对象或状态，避免装饰决定版面。顶部、中部、底部信息密度均衡，不无限增高。

## 原生draw.io实现

按[flowchart-spec.md](flowchart-spec.md)写本项目JSON，含真实nodes/edges、几何及已确认的内容/制作授权。当前会话已有授权和选定方案可直接作为字段依据，不为脚本布尔值再问一次。

```text
python <本包>/scripts/build_drawio.py <项目>/figure.spec.json <项目>/figure.drawio
python <本包>/scripts/validate_drawio.py <项目>/figure.drawio --spec <项目>/figure.spec.json --profile strict --json-out <项目>/checks/drawio.json
```

生成器使用本包scripts/lib内实现。新图strict；已有图局部返修用legacy-audit并保留节点ID和原源；不把已有精确XML强制迁移成YAML工程。坐标使用draw.io用户单位，物理mm由导出契约单独管理。

每条语义边绑定真实source/target ID，端口在目标边界。用明确waypoints组织正交路径；不要用游离隐形节点伪造主干。交叉不等于连接，真实汇合有明确接点。箭头末段在转折后保留可见直线，线头不悬空、不压字、不接到无关容器。

有本机draw.io Desktop且需PNG/PDF/SVG时使用其已安装导出能力；先查看当前CLI帮助，再导出到任务目录，Windows后台启动保持隐藏。检查实际文件和编辑性；没有导出器时保留draw.io并说明哪些格式尚未生成，不把SVG改后缀当PDF。

## 原生SVG路径

用户指定SVG或当前源已是SVG时，用rect/path/text/g等可编辑对象实现同一关系记录；文本保留为文本，设置实际width/height与viewBox。不把整张位图包进SVG冒充可编辑源。保留一份节点/边记录便于逐线核对。

```text
python <本包>/scripts/audit_svg_schematic.py <项目>/figure.svg --min-pt 5 --max-pt 12 --max-width-mm 170 --json
python <本包>/scripts/check_svg_size.py <项目>/figure.svg --width-mm 170 --max-height-mm 150 --min-font-pt 5 --json-out <项目>/checks/svg_size.json
```

示例尺寸/阈值必须按任务替换。SVG文字与几何检查不是拓扑科学审核；逐边对照关系清单。SVG转PNG/PDF使用现有可靠渲染器，不因包内未附渲染引擎擅自安装软件。可编辑源、真实导出与预览分别说明。

## 局部返修与验收

“逻辑不变”允许重排；“结构位置不变”锁定几何。只改箭头时复用既有节点和内容检查；更改节点位置后检查相邻边和整体留白。目标宽度适配要看实际物理尺寸和文字，不能只改SVG根属性把字整体缩小后宣称可读。

检查ID唯一、源/目标绑定、必要路径、无意多/少边、节点相交、越界、文字适配、箭头方向、真实汇合和最终导出。自动结果与人工视觉判断分别报告；实际看图逐条追踪连线，并在论文尺寸检查。完整图注按[captions.md](captions.md)移到图外。
