# 从证据与参考共同形成方案

## 一个设计任务

先写清图的问题、现有证据及不能改变的样本/统计口径；每个面板承担互补作用，例如总体分布、配对关系、量化比较、局部过程或适用边界。不同指标并不自动意味着不同信息层次；两个面板如果只重复同一证据，应合并或重新分工。用户限定图数时不擅自追加。

图区面积与需要辨认的信息相称。主图必须承担具体问题，不能靠空白扩大体量，也不靠堆满数字充实。删去冗余数字后同步调整面积和布局。主次布局、等大矩阵、横向/纵向排列由比较关系决定，不固定“一主多辅”。

对每个核心读图问题，指出哪个源字段能回答、统计单位是什么、面板上从哪里读。总体幅度、联合方向和个例过程可以互补。同名指标跨时间尺度或样本层级时，写清本图需要哪个层级的分布、典型值或联合分类。区分图中可直接读出、需要查表换算和图中缺失的答案；缺失时核实源数据是否具备。

## 图库参考学习

图库入口：https://chutj.github.io/gallery/ 。本包自带检索器：

```text
python <本包>/scripts/search_gallery.py --index <项目>/.figure-references/public.json --list-types
python <本包>/scripts/search_gallery.py --index <项目>/.figure-references/public.json --type 热力图 --query correlation --limit 4
```

仅用标准库。索引不存在时下载公开JSON；有缓存时直接读取，只有明确需要更新才加`--refresh`。记录缓存时间，不称缓存为实时最新。查询词按AND匹配；先图型后问题/布局关键词，无结果时适度放宽。无需下载整个图片库、安装网站或上传用户数据。

查看通常2–4个有希望的候选原图与详情，选一个主参考、必要时补局部参考。用户参考优先；网络不可用时复用可见参考并说明覆盖范围。只读标题或Design lessons不算看过图；必须实际打开图像。合并分类如箱线/小提琴/雨云须看原图判别。

每个采用的参考只记几项：来源链接/图号；观察到的面板结构、配色语义、线宽或注释方法；它如何帮助读者完成本图的一项比较；准备如何实现。若两个参考分别适合两个子图，再看两类信息能否按同一对象就近对读。估计的字号/HEX标为近似。参考论文的样本、p值、机制和结论不属于用户，不可移植。

参考原图许可按记录中的rights核对；图库代码许可不覆盖论文图片。默认借鉴设计、用用户数据重新实现，不复制论文像素进结果图。记录里区分“读过规范”“实际看过参考”“运行过代码”。

## 三个共同设计的候选

每张图总共三个候选，全部使用同一科学约束，可共享参考。设计差异来自需要凸显的比较，而非工具品牌。

| 方案字段 | 要回答的内容 |
|---|---|
| 表达重点 | 读者首先看到哪个证据层次？ |
| 面板与排列 | 哪些子图、采用何种图型、阅读顺序及大致比例？ |
| 统计读法 | 点/线/色/大小分别表示什么，分母和区间是什么？ |
| 借鉴 | 实际看过的哪个参考，采用什么安排？ |
| 取舍 | 用一个实际组别演示关键读法。哪些比较更快，哪些要查表，哪些问题在此版没有答案？ |

可供思考的差异包括：分布与摘要的主次；逐对象配对关系与总体构成；总体证据与局部过程；空间主图与区域摘要；方法图的并行路径与泳道/分层结构。这些不是强制A/B/C模板。不能通过筛掉对象或增加未经授权统计制造差异；只支持两个有效方案时如实说明。

问答前用同一组读图问题试读各案。仍在现有职责内的方案都应覆盖核心问题，允许视觉主次不同。某案偏重个例或查表、因此丢掉必需的总体比较时，先用已有数据补足最小表达；若有意改变图的职责，把具体损失写入选项供用户决定。有多个可行案时，推荐一个并说明它如何完成最重要的比较。密集数表适合精查；快速比较还要看读者能否沿共轴、对齐位置或紧邻编码读出差别。

不需要为每案读一遍全部技能、查一轮图库或建设三套工程。方案卡/结构草图足以决定时先给卡片；真实样稿使用相同数据与范围，不以模拟结果冒充用户结果。

## 三案选择与一次问答

在第一次给三案时完成可预见的偏好选择。先说推荐哪案及理由，再用一行说明已沿用的约定，例如“同系列横版、关键值就地标、共用图例放底部”。三案共用这套约定，只解释各案真正有区别的读法与代价。

- 通常只问选哪案或哪些面板。若仍有会改变面板分工、布局或数据呈现层级的独立偏好，同轮加一至两项，给出选项、建议默认及影响。已经写进三案的分歧直接通过选案回答；稿件、用户原话或成品已经确定的事项直接沿用。
- 可问“幅度需要看整组分布，还是典型值足够？”“版面有限时优先保留总体比较，还是展开个例？”只有相应取舍尚未确定才问。字号、刻度、间距、引线避让等直接在初稿中解决。若作者点名某项参数，照其要求执行。
- 在同一条答复中把方案和选项讲清；可用一次 `request_user_input_async` 收集答案。让作者一句话就能选，如“B，保留完整分布，其余按推荐”。只回“B”就采用该案和已说明的可选偏好默认值。方案尚未选定时等待选择；影响统计有效性的缺口单独指出，不能用默认偏好补齐。
- 明确选择、跨案组合或授权代选后，记录最终组合、必保信息和例外，直接制作。组合有科学冲突时才围绕具体冲突澄清。已选方案的局部返修可直接执行并保留其余已接受的决定。
