# 科研制图完整版

将科学证据组织、真实参考学习、制图实现和质量检查放在同一个流程内。常规任务直接使用本包的规范与脚本，不先转交nature、gallery或三个方法图技能，也不要求另装它们。Python/R、绘图库、字体、PDF渲染库、可选draw.io Desktop等运行环境仍须可用；本包不自动安装依赖。

本包基于 2026-11-17 的整合快照和后续制图返修更新。来源、许可和修改见[来源说明](references/provenance.md)。上游更新经核对后按需合并。同一任务使用一个入口。

## 使用模式与共同约束

- **新图/重新设计**：理解读图任务与项目风格 → 学习参考 → 同轮给三案、推荐和必要偏好问题 → 用户选定 → 制作、自查并交付。
- **只讨论含义/方案**：做到用户要求的阶段，不自动进入制作。
- **已接受图的局部返修**：沿用方案、源文件、语言、后端和通过的检查，直接改指定部分；不重新给三案，不重新找参考。
- **用户已指定组合或明确委托代选**：执行当前指令，记录依据，不重复问选择。

当前要求 > 最新接受决定 > 已确认个人偏好 > 默认风格。科学定义和数据权限始终保留。只改展示时不重新训练、率定、重采样或重算科学指标，不改原始数据；必要的展示统计必须属于任务授权。图形变化不构成新科学发现。

## 1. 理解一次，形成一份制作约定

先读最新接受图、实际数据/摘要、源代码、图注和相关正文。版本依明确记录和用户指定判断，不仅看文件名。已有figure-worklog.md继续使用；新任务用一份简短记录承载：

1. 图回答的问题、证据实际支持的结果和不能推出的解释；未确定结论时保留问题，不先定结论再筛数据。
2. 每个信息层次的单位、分母、样本、配对/聚合顺序、指标、区间定义；方法图记录实际节点与有向关系。
3. 允许改动、必须复用部分、语言、目标宽高、格式、颜色及已接受/被否定偏好。
4. 从正文或已确认的目标提取一至三个实际读图问题，写明读者要在哪个尺度、对哪些对象做何种比较。用这些问题筛选方案，并在成图后验读。据此限定本轮数值、语义、排版和交付的核对范围。

同一图号若同时有文稿设计与较晚采用的成品，从文稿核对科学定义，从成品、图注和采纳记录核对当前图的职责。两版职责有差异时，在方案卡中点明取舍。用户明确要求盲设计时，仅用其允许的材料拟案。“从零设计”允许重新布局和选图型。

缺失信息先从现有材料查找，只询问会改变科学关系或范围的缺口。读[statistics-and-preferences.md](references/statistics-and-preferences.md)，将正确性与个人审美分开。从同系列已采纳图及其实际代码提取可复用的样式，在已有制作约定中简记字体层级、颜色角色、面板和图例位置。没有同系列成品时，按本包的个人偏好起步。实现细节由制图者决定。

## 2. 参考借鉴与三案联合设计

读[design-and-choice.md](references/design-and-choice.md)。先明确证据和科学边界，再围绕问题查找、实际查看参考图，提炼构图/编码；将两部分共同用于全部候选。新设计明确使用本完整版时包含必要参考学习；局部返修复用既有参考。用户提供具体参考时优先使用，不额外铺开检索。

每张图默认**总共三个**候选A/B/C，按表达重点、统计读法和面板组合区分。不要按技能分案，不给每个子图或工具各出三案，不以换色/边框凑数。方案可以共享参考；若现有证据只支持少于三种有效方案，说明限制，不造数据或图型。用户明确指定数量优先。

## 3. 问答决定组合，再制作

呈现三张简短方案卡或布局草图：每案讲清面板及排列、统计读法、读者能比较什么、参考借鉴及主要代价。默认方案阶段不制作三套精修成品；用户明确要实际样稿时，用同一真实数据制作足以判断的预览。

首次方案答复同时给出推荐组合和将沿用的偏好。按[三案选择与一次问答](references/design-and-choice.md)将选案与仍影响构图的偏好集中问一次。可以只回 A/B/C、跨案组合，或在选择后补一句例外。已有明确指示时直接执行。

**未收到选择，不把推荐、预选项或等待超时当成回答，不进行依赖选择的正式制图。**可以继续核实数据与素材。收到清楚选择后记录最终面板、顺序、统计口径和用户决定，直接制作，不再请求重复批准。这是用户要求的设计选择环节。

## 4. 一个主源实现与迭代

按任务读取一条实现路线，不为能力数量重复制作：

- 数据图、地图、数据与方法混合组图：[data-figures.md](references/data-figures.md)。Python/R沿用当前明确选择或已有脚本；地图沿用地理资源。
- 方法/架构图：[method-figures.md](references/method-figures.md)，使用本包draw.io构建器或原生SVG，保留编辑对象。

先实现关系、坐标与编码，再处理字号、间距和标注。科学逻辑不变允许重排；用户明确“不调结构”时锁定接受版位置。只在新版本/指定目录写作，不覆盖已接受图或共享配置。

重复面板先用一组真实数据排通基本读法，再用标注最拥挤或数值接近的组试排。成图与同系列已接受图按相同发表宽度并看，及时校正字号层级、色义和视觉密度。单图则直接按目标宽度验读。循环为：查看真实渲染 → 定位具体问题 → 修改同一主源 → 重新导出 → 复查受影响处。问题解决即停止；不凑迭代次数、不无上限美化。

## 5. 一次合并审核与交付

读[qa-and-delivery.md](references/qa-and-delivery.md)。同一最终导出把统计对应、参考设计落实、图例语义、几何和视觉检查合并；不同工具各检查其独有内容，不对同一问题因技能来源不同重复运行。保留真实失败和限制，不降低阈值掩盖遮挡。自动通过不等于视觉或科学审核通过。

实际写图名图注时读[图注规范](references/captions.md)：短标题后接必要科学定义；执行核对、未重算等记录放工作日志。用户要求哪些格式就交付哪些，不自动新增PPT、Word、补充图或压缩包，不对外发送。

交付简述选定组合、关键变化、真实检查及文件链接。新反馈落到对象和验收范围；当前图偏好只写项目，明确要求固化才修改本包或原技能，并说明修改对象。
